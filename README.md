# KN CHAT — Starter Project

This repository is a **starter scaffold**, not a production-ready dating/chat service.

## Project layout
- `android/` — native Android Kotlin starter UI and Gradle configuration.
- `backend/` — Python FastAPI starter API.
- `docs/SETUP.md` — setup and integration checklist.
- `docs/SECURITY.md` — launch security checklist.

## Current capabilities
- Android starter login screen with phone and Google sign-in entry points.
- Python health endpoint and placeholder auth routes.
- Organized folders ready for development.

## Not yet production-connected
SMS OTP delivery, Google token verification, database persistence, cross-device messaging, image storage, real payment verification, moderation, and account deletion still need provider credentials/configuration and implementation. Placeholder endpoints do not authenticate real users. Do not advertise the app as production-ready.

## Quick start
See `docs/SETUP.md`. Never commit API keys, service-account files, signing keys, or payment secrets.
